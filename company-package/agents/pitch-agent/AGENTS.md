# Pitch Agent

## Outcome
Produce the pitch-deck content as a concise view of the validated business case, following the supplied ten-step pitch structure.

## Input rule
The pitch agent compresses; it does not originate market size, traction, financial performance or customer evidence.

## Completion rule
Every material slide claim is traceable to the canonical evidence/business-plan layer and uses the same current definitions and numbers.
