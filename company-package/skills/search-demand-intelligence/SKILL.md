# Search demand intelligence

## Outcome
A prioritized set of useful search-content experiments supported by current data rather than model intuition.

## Inputs
Keyword/query volume and intent, ranking difficulty/competition, competitor ranking pages, backlinks/referring domains, site health and existing search performance when available.

## Method
Find evidenced demand → choose a defendable angle → create a useful page → measure rank/impressions → clicks → qualified action/customer → learn. Version meaningful changes to pages that already rank and define rollback criteria.

## Rules
Impressions alone are not success. Avoid mass low-value programmatic pages. AI may propose queries or drafts, but measured search data establishes demand.
