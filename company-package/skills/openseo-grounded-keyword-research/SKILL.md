# OpenSEO grounded keyword research

## Capability gate
Use only when an approved OpenSEO MCP/capability is available. Otherwise apply `search-demand-intelligence` with other current, sourceable data.

## Outcome
A prioritized keyword/search opportunity set tied to the venture's current business, goal, market, competitors and target pages.

## Workflow
1. Load project/venture context before keyword calls.
2. Check the research log and reuse sufficiently recent equivalent research before incurring new API cost.
3. If first-party Search Console/performance data exists, examine near-ranking/striking-distance queries before broad discovery.
4. Expand from a small set of seed problems/topics; hydrate candidates with volume, difficulty, intent, CPC/trend where available.
5. Inspect actual SERPs when intent ambiguity would change the recommendation.
6. Remove duplicates, off-intent and irrelevant branded terms.
7. Prioritize product/business fit, intent and plausible competitiveness over largest volume.
8. Record selected terms, target page/experiment and research date; do not persist/save external tool state without authorization.

## Rules
Never invent missing metrics. Search interest is evidence of attention/problem language, not willingness to pay.
