# Creative generation review loop

## Outcome
A connected set of campaign assets that preserve product/brand identity, satisfy the brief and have a review trail.

## Method
1. Establish approved product/brand reference assets.
2. Define deliverables, use context, acceptance criteria, model-choice rationale and budget/approval mode.
3. Generate V1.
4. Inspect actual output and list observable defects.
5. Write a targeted revision that fixes those defects while naming what must remain unchanged.
6. Generate only justified next versions; preserve them for comparison.
7. Select and approve the final asset before release.

## Rule
Aesthetic confidence from the agent is not final approval. Track observed spend separately from estimated/listed rates.
