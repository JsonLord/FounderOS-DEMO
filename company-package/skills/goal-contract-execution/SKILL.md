# Goal-contract execution

## Outcome
An agent keeps working toward a defined result without confusing intermediate activity with success.

## Contract
Before execution record: objective, required inputs, allowed tools/sources, constraints, deliverables, acceptance tests, pass/fail threshold, maximum time/cost, external-action authorization and stop/escalation conditions.

For ambiguous high-impact jobs, ask targeted clarifying questions until the pass/fail test is stable. After execution, audit each criterion and report PASS, FAIL or BLOCKED with evidence.

## Rule
Do not move goalposts after seeing results. If criteria need to change, create a new version of the goal contract.
