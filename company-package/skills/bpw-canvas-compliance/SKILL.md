# BPW Canvas compliance

## Outcome
A requirement matrix showing whether a Canvas package is submission-grade and understandable to third parties.

## Package requirements
Require the one-page Canvas, an explanatory overview, explanations for all nine components, and an outlook describing where the company aims to be in roughly three to five years. The source workshop recommends about one to two pages of explanation per field. Sustainability must be integrated into the segment descriptions.

## Audit dimensions
Check: clear value proposition/customer benefit; meaningful segmentation and market/competition analysis; fitting relationships/channels; accountable key activities; adequate resources, location/legal-form/team logic; purposeful partners; validated/plausible pricing and revenue; plausible costs; coherent whole; realistic opportunities/risks; readable presentation.

## Completion gate
Return PASS only when every applicable criterion is satisfied or explicitly justified as not applicable. Missing evidence is not converted into persuasive prose.
