# Campaign auto-research

## Outcome
A recurring evidence report that recommends the next controlled GTM test.

## Analyze
Segment attributes, triggers, source, role, channel, message/angle, offer, reply type, call rate, commitment/payment and cost where available.

## Loop
Collect → normalize → compare cohorts → surface patterns/contradictions → spot-check raw records → recommend one or a small number of changes → run next experiment → update ICP/offer/channel evidence.

## Rule
Correlation in a small campaign is a hypothesis, not causation. Preserve sample size and uncertainty; never rewrite every campaign variable at once.
