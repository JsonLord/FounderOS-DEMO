# Creative review loop

## Flow
Campaign objective → canonical product/brand reference → deliverables/use context → acceptance criteria → generation budget/approval mode → V1 → inspect actual output → name concrete defects → targeted revision → next version → compare → operator approval → publish/test.

## Review dimensions
Identity/reference consistency, claim accuracy, legibility, product geometry/details, composition, motion/camera, audio, platform format, CTA clarity, and compliance with the experiment brief.

## Cost control
Before another paid generation, record why the next version is needed and what defect it is intended to fix. Preserve observed spend separately from vendor-listed rates or estimates.

## Rule
'Make it better' is not a revision instruction. State the observable defect, desired correction and what should remain unchanged.
