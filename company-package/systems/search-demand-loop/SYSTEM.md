# Search demand loop

## Flow
Customer/problem hypothesis → current keyword/query data → intent/volume/difficulty → competitor ranking pages and backlinks → defendable angle → useful page/content → index/rank measurement → impressions → clicks → qualified actions → customers → learn/revise/rollback.

## Rules
- Model intuition may suggest keywords but cannot establish demand.
- Prefer current measured query data when available.
- Do not equate impressions with business value.
- Avoid mass low-value programmatic pages solely because AI can generate them.
- Version major SEO changes and define rollback criteria before editing a page that already ranks.
- Feed customer/revenue outcomes back into GTM and financial assumptions, not just traffic metrics.
