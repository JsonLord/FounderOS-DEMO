# Transcript 06 — agentic lead generation

## Source contribution
The source proposes six shifts: waterfall company sourcing, waterfall contact finding, recurring agent jobs, goal-mode execution with pass/fail criteria, automatic campaign research, and reuse of open-source capabilities.

The waterfall principle starts with the highest-fidelity/lowest-cost source appropriate to the ICP, normalizes and deduplicates results, then uses broader or more expensive discovery only for unresolved gaps. Goal mode defines what 'done' means before the agent runs. Campaign auto-research periodically analyzes which prospect traits and messages produce responses.

## Founder OS adaptation
Use staged sourcing and enrichment with per-field provenance/confidence. Run prospect/campaign intelligence as recurring loops. Every list-building or campaign setup job gets a goal contract and audit step.
