# Transcript 03 — iterative creative campaign

## Source contribution
The source demonstrates a campaign workflow in which one approved product reference anchors multiple assets. Revision is specified before generation: create a version, inspect the actual result, name concrete defects, rewrite direction for those defects, then regenerate and compare. Earlier takes remain available. Cost/credit usage and agent autonomy are kept visible, while the operator makes the final creative decision.

## Founder OS adaptation
For fake doors and offer campaigns, establish a canonical reference asset and usage brief before generating variants. Define what to inspect and how many review rounds/budget are allowed. Prefer surgical corrections over vague style requests. Keep version history and rationale.

## Loop
Brief + reference + budget → V1 → defect review → targeted revision → V2/V3 → comparison → operator approval → publish/test → demand evidence.
