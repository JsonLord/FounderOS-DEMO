# Transcript 04 — sales operating system

## Source contribution
The source separates sales into intelligence gathering and action. It proposes a central markdown-based sales second brain fed from raw sales tools through a reconciliation/filter layer. Dashboards and AI skills consume that canonical context; completed actions feed back into it.

Suggested context includes calls/transcripts, ICP, offer, positioning, sales process, deal histories, campaign histories, reports, templates and skills. Suggested recurring routines include a morning reconciliation/call-prep pass, CRM synchronization/hygiene, call scoring/coaching, and periodic reporting.

## Founder OS adaptation
Treat the second brain as the canonical context layer for agents, not a replacement for source systems. Every derived fact keeps provenance and last-updated time. Give each operator a 'today' view driven from the same context: priority prospects, calls, next actions, pipeline state, experiments and unresolved evidence gaps.

## Loop
Source systems → reconcile/filter → canonical context → dashboard + agent action → source-system update → canonical context.
