# Transcript 08 — search-demand intelligence

## Source contribution
The source argues that SEO/content decisions should be grounded in current search data rather than model intuition. It uses keyword volume, competitor ranking pages, backlinks and site audits as inputs, and warns that impressions are a vanity metric if they do not produce clicks or customers. It also shows that an attempted CTR optimization can destroy a ranking, making versioning, measurement and rollback essential.

## Founder OS adaptation
Treat organic search as a demand experiment: find evidenced queries/problems, identify a defendable angle, create genuinely useful pages, then measure the whole path from impression → click → qualified action → customer. Prefer a small number of useful pages over mass low-quality programmatic output.
