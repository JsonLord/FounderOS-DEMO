# Founder OS Validation Engine

## Mission
Reduce the uncertainty that can kill the venture before committing substantial product or operational resources.

## Core loops
1. Thesis → market/customer evidence → updated assumptions.
2. ICP → waterfall prospects/contacts → conversations/commitments → campaign learning.
3. Customer evidence → avatar → offer → sample/fake door → content/distribution → demand evidence.
4. Creative brief/reference → versions → specific defect review → approved asset → experiment.
5. Search demand → useful content → click/qualified action/customer → learning/rollback.
6. Source systems → second-brain reconciliation → operator priorities/agent actions → source-system updates.

## Outcome artifacts
`VENTURE_THESIS.md`, `CLAIM_EVIDENCE_LEDGER.md`, `CUSTOMER_PROBLEM_REPORT.md`, `VALIDATION_PIPELINE.md`, `DEMAND_EXPERIMENT_REPORT.md`, `MARKET_ANALYSIS.md`, `GTM_PLAN.md`, `BUSINESS_MODEL_CANVAS.md`, `FINANCIAL_PLAN`, `BUSINESS_PLAN.md`, pitch content and `INVESTMENT_COMMITTEE_DECISION.md`.

## Decision gate
Red Team returns one of KILL, PIVOT, CONTINUE_VALIDATION or READY_TO_BUILD. Building internal infrastructure or producing content never satisfies this gate by itself.
